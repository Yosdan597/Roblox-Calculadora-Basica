# Calculadora Física en Roblox

Un proyecto de aprendizaje que implementa una calculadora funcional completamente dentro del motor Roblox, utilizando bloques 3D interactivos como interfaz en lugar de una GUI tradicional.

## 🎯 Objetivo del Proyecto
Aprender y aplicar conceptos fundamentales de programación en Lua —variables, operadores aritméticos, condicionales y eventos— creando un sistema interactivo que simula el comportamiento de una calculadora real.

## ✨ Características
- **Interfaz física:** Bloques 3D que representan números (0-9) y operadores (+, -, ×, ÷, =, C)
- **Sistema de estado:** Implementación de una máquina de estados mediante `leaderstats` para gestionar pantalla, memoria y operación actual
- **Operaciones básicas:** Suma, resta, multiplicación y división con validación de errores (ej: división por cero)
- **Persistencia de datos:** Uso de `NumberValue` y `StringValue` para mantener el estado durante la sesión}
- ## 📖 Aprendizajes Clave
- Cómo gestionar estado en aplicaciones interactivas
- Implementación de lógica condicional para operaciones matemáticas
- Uso de eventos para crear interfaces 3D interactivas
- Validación de entrada de usuario (ej: evitar división por cero)
- ## 🔮 Posibles Mejoras
- Implementar operaciones avanzadas (porcentaje, raíz cuadrada)
- Añadir soporte para números decimales
- Implementar historial de operaciones
- Crear una GUI que refleje los valores actuales
